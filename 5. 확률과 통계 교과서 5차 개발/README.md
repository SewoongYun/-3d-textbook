# 확률과 통계 3D 교과서

책상 위에 펼쳐진 3D 책에서 고등학교 **확률과 통계**의 핵심 개념 15개를 **예측 → 실험 → 증명** 순서로 배우는 웹 교재입니다.
로그인·설치 없이 브라우저에서 바로 열립니다.

- 레슨을 고르면 표지가 열리고, 넘길 때마다 책장이 말리듯 넘어갑니다.
- 내 답을 먼저 고르면 오른쪽 쪽에서 **잉크 펜화 모형**이 일어서고, 슬라이더로 조건을 바꾸며 관찰합니다.
- **종이 덮개**를 들추면 정답과 틀린 보기의 이유가 나오고, 도전 문제를 맞히면 책장에 **도장**이 찍힙니다.
- 교사용 노트(수업 질문·단순화한 부분·오개념·검산 방법)와 레슨별 근거가 책 안에 들어 있습니다.
- 3D가 안 되거나 번역·읽어 주기가 필요하면 **글 화면(Text version)** 으로 같은 내용을 배울 수 있습니다.

## 조작

- 아래 조작 바: 목차 · ◀ ▶ 레슨 넘기기 · ▷ 시연(스페이스 일시정지, Esc 멈춤) · 소리 · 밝기 · 움직임 줄이기 · 교사용 노트 · 글 화면
- 3D 화면: 끌어서 돌리기, 휠로 확대·축소, 두 번 클릭하면 시점 처음으로
- 덮개를 누르면 정답, 모형을 누르면 슬라이더 값이 하나씩 바뀝니다.
- 주소 끝에 `?no3d` 를 붙이면 3D 없이 글 화면만 엽니다.

## GitHub Pages로 배포하기

이 폴더의 파일을 **그대로** 저장소 맨 위(루트)에 올리면 됩니다. 빌드 과정은 필요 없습니다(`index.html` 이 이미 만들어져 있음).

1. GitHub에서 새 저장소를 만듭니다(예: `probability-3d-book`, Public).
2. 저장소 첫 화면의 **uploading an existing file** 을 눌러, 이 폴더 안의 파일과 폴더(`index.html`, `lib`, `src` 등)를 모두 끌어다 놓고 **Commit changes**.
3. 저장소 **Settings → Pages** 에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 정하고 Save.
4. 1~2분 뒤 `https://<내 아이디>.github.io/<저장소 이름>/` 에서 열립니다.

> 숨김 파일(`.nojekyll`, `.gitignore`)이 끌어다 놓기로 안 올라가도 동작에는 문제없습니다.

## 파일 구성

```
index.html        완성된 페이지 (build 결과물, 배포되는 파일)
lib/three.min.js  3D 라이브러리 three.js r128 (MIT). 없으면 cdnjs에서 불러옴
src/              원본
  lib.js            수학 계산·난수·SVG 도우미
  lessons_1~3.js    레슨 15개 (상황·예측·슬라이더·계산·2D 그림·3D 모형·적용 문제)
  teacher.js        교사용 노트와 수치의 출처
  ink.js            잉크 펜화 재질, 윤곽선, 손글씨 꼬리표
  pages.js          책장에 인쇄되는 그림(왼쪽·오른쪽 쪽, 표지)
  book.js           책상·책·표지 열기·책장 넘기기·덮개·도장·카메라
  app.js            학습 흐름, 유리 패널, 조작 바, 시연, 글 화면
  shell.html, style.css
build.js / build.ps1  src 를 합쳐 index.html 생성
test.js           교과서 공식 값을 직접 세어 본 값과 비교하는 검산
serve.js          내 컴퓨터에서 미리 보는 간단한 서버
CHANGELOG.md      차시별 변경 기록
```

## 고치고 다시 만들기

1. `src/` 의 파일을 고칩니다. 레슨 하나는 `src/lessons_*.js` 의 객체 하나입니다.
2. (Node가 있으면) `node test.js` 로 검산합니다.
3. `node build.js` 또는 PowerShell에서 `.\build.ps1` 을 실행하면 `index.html` 이 새로 만들어집니다.
4. 바뀐 파일을 저장소에 다시 올립니다.

내 컴퓨터에서 미리 보기: `node serve.js` → http://localhost:8123/
브라우저 콘솔에서 `__app.pageReport()` 를 실행하면 책장 글자 잘림·넘침 목록을 볼 수 있습니다.
